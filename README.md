일반 HTTPS 다운로드 링크입니다. Safari 등 브라우저에서 링크를 눌러 ZIP을 내려받고 파일 앱에서 압축을 풀면 됩니다.

## 공동작업

이 공개 브랜치의 링크는 공동작업자도 사용할 수 있습니다. 내려받은 애셋과 규격을 각자의 개발 작업에 사용하세요. 이 브랜치는 배포 자료를 보관하며, 앱 개발의 기준 브랜치는 `main`입니다. 이 애셋을 만드는 작업에서 실제 대화 서버 기능은 구현하지 않았습니다.

`vercel.json`은 이 다운로드 브랜치에서 자동 앱 배포가 실행되지 않도록 합니다.

## 파일 확인

`SHA256SUMS.txt`에 각 ZIP의 SHA-256을 적었습니다.
