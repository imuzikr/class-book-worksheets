# 책봄 독서 여정 이미지

승인된 대륙형 여정 맵과 초급·중급·고급 캐릭터 각 10종을 웹 화면에 맞게 최적화한 파일입니다.

- `map.webp`: 1536 × 1024. 그림 전체와 경로 좌표계를 함께 사용하며, `cover`로 잘라서 표시하지 않습니다.
- `beginner-01.webp` ~ `beginner-10.webp`: 사용자 제공 판타지 캐릭터 세트, 640 × 640, 투명 배경.
- `intermediate-01.webp` ~ `intermediate-10.webp`: 첫 번째 캐릭터 세트, 640 × 640, 투명 배경.
- `advanced-01.webp` ~ `advanced-10.webp`: 전통 무술복 캐릭터 세트, 640 × 640, 투명 배경.

파일명의 세트 이름은 이미지 구분용이며 레벨 잠금이나 추가 경험치 조건을 뜻하지 않습니다. 번호와 세트를 함께 저장하고, 이름·경로는 `lib/readingCharacterCatalog.js`에서 공유합니다.

중급·고급 캐릭터의 원본은 각각 1254 × 1254 PNG입니다. 원본 그림과 선택된 맵을 다시 그리지 않고, 크기와 인코딩만 웹용으로 변경했습니다. 캐릭터의 투명도 채널은 리사이즈 결과를 손실 없이 보존했습니다.

초급 원본은 사용자 제공 `fantasy-clay-characters.zip`의 1024 × 1024 PNG 10개입니다. 흰 배경과 지면 그림자는 이미지 편집 도구로 투명화했고, 얼굴·포즈·의상·책·원래 소품을 유지하도록 참조 편집했습니다. 생성 편집 특성상 미세한 재묘사가 있을 수 있으며 원본 픽셀을 그대로 옮긴 파일은 아닙니다. 투명화 PNG를 웹용 WebP로 최적화했습니다. 제공 ZIP과 원본 PNG·투명화 PNG는 작업 산출물 `bookbom-beginner-characters`에 별도로 보존합니다.

원본 디자인 자료는 작업 산출물 `bookbom-characters-renamed`와 `bookbom-journey-prototype/assets/journey-background.png`에 보존되어 있습니다. 화면에서는 이 폴더의 WebP를 사용합니다.
