# 책봄 독서 여정 이미지

승인된 대륙형 여정 맵과 캐릭터 세 묶음(수련생 · 무도가 · 영웅 각 10종)을 웹 화면에 맞게 최적화한 파일입니다.

- `map.webp`: 1536 × 1024. 그림 전체와 경로 좌표계를 함께 사용하며, `cover`로 잘라서 표시하지 않습니다.
- `zodiac-01.webp` ~ `zodiac-10.webp`: **수련생 · 십이지** — 사용자 제공 무술 도복 십이지 세트, 640 × 640, 투명 배경.
- `animal-01.webp` ~ `animal-10.webp`: **무도가 · 동물** — 첫 번째 캐릭터 세트, 640 × 640, 투명 배경.
- `fantasy-01.webp` ~ `fantasy-10.webp`: **영웅 · 판타지** — 사용자 제공 판타지 캐릭터 스탠딩 세트, 640 × 640, 투명 배경.

파일명의 앞부분이 저장 열쇠(`zodiac` · `animal` · `fantasy`)이고, 화면의 등급 이름(수련생 · 무도가 · 영웅 — 한때 초급 · 중급 · 고급)과 캐릭터 이름 · 경로는 `lib/readingCharacterCatalog.js` 한 곳에서 정합니다. 묶음은 레벨 잠금이나 추가 경험치 조건을 뜻하지 않습니다 — 학생이 자유롭게 고릅니다.

## 2026년 11월 묶음 바꾸기

선생님 요청으로 십이지를 새 첫 등급(수련생)으로 들이고, 그때까지 초급이던 판타지를 맨 위 등급(영웅)으로 올리고, 그때까지 고급이던 전통 무술복 동물 세트(`advanced-*.webp`)는 내렸습니다. 파일은 `beginner-NN` → `fantasy-NN`, `intermediate-NN` → `animal-NN`으로 이름만 바꿨습니다(그림은 그대로). 이미 저장된 학생의 선택(`users/{uid}.readingCharacter`의 옛 열쇠)은 `lib/readingCharacter.js`가 같은 모습으로 옮겨 읽습니다 — `beginner` → 판타지, `intermediate` → 동물, `advanced`(내린 묶음) → 같은 번호의 동물.

원본은 사용자 제공 `zodiac-martial-arts.zip`의 1024 × 1024 PNG 10개(뱀 · 말은 없음)이고, **흰 바탕에 노란 '기운'(빛 번짐 · 번개 · 불꽃)과 바닥 그림자가 함께 그려져** 있었습니다. 도복 · 흰 털도 흰색에 가까워 '흰색만 지우기'로는 도복이 뚫리고 번짐이 남아(어두운 독서 맵 · 친구 목록에서 흰 테로 보임), `scripts/prepare-zodiac-art.py`로 걷었습니다.

- 바깥 흰 바탕에서 색이 매끈하게 이어지는 곳만 따라 들어가 '확실한 배경'을 잡고, 털 · 띠 · 그늘진 도복 같은 '확실한 캐릭터'와 동시에 퍼뜨려 **가장 센 윤곽에서 만나게** 합니다(분수령). 빛을 받아 노랗게 물든 도복 가장자리는 윤곽 안쪽이라 지켜지고, 번개 · 불꽃 조각은 배경 쪽으로 갑니다.
- 기운과 바닥 그림자는 모두 걷었습니다 — 다른 두 묶음처럼 캐릭터만 남깁니다. **호랑이 주먹의 불꽃은 남겼습니다**(주먹에 붙은 그림의 일부).
- 자동으로 가르기 어려운 곳 — 용의 민트빛 번짐 · 흰 바탕과 거의 같은 창날, 쥐 바지 옆의 번짐 주머니 — 은 스크립트 안 `PER_IMAGE`에 눈으로 잰 점 · 다각형(원본 좌표)으로 적었습니다.
- 틀: 열 장 모두 **같은 배율**(가운데 960px 창 → 640)이라 그린 크기 그대로 견줘지고, 발끝은 아래에서 10px 위입니다. 투명도를 곱한 채로 줄여 가장자리에 흰 테가 생기지 않고, WebP 품질 85(투명도는 손실 없음)로 한 장 20~50KB입니다.
- 다시 만들기: ZIP을 새 빈 폴더에 풀고 `python3 -I scripts/prepare-zodiac-art.py <그 폴더> <내보낼 폴더>`(numpy · Pillow, 한 번에 1분쯤). 지금 파일과 바이트까지 같게 나옵니다(2026년 11월 확인). 그림을 새로 받으면 `PER_IMAGE`의 점 · 다각형은 그 그림에 맞게 다시 재야 합니다.

원본 디자인 자료는 작업 산출물 `bookbom-characters-renamed`와 `bookbom-journey-prototype/assets/journey-background.png`에 보존되어 있습니다. 화면에서는 이 폴더의 WebP를 사용합니다.
