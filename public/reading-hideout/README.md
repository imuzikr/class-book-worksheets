# 개인 아지트 그림

검토를 거친 수정본 v2를 사용합니다. 본품은 30종류 × 네 테마 = 120개이며, 기본 가구 일곱 장과 조합용 빈 벽 선반 네 장은 별도입니다. 작은 벽 선반 아이템은 빈 변형 두 인스턴스로 그려 개별 소품과 장식이 중복되지 않게 합니다.

- `items/{종류}/{테마}.webp`: 120개 본품. 원형 러그 세 장은 시점을 맞춘 v2입니다.
- `helpers/empty-wall-shelf/{테마}.webp`: 실제 배치·상세에서 사용하는 빈 선반.
- `desk-basic.webp` 등 기본형 일곱 장: 성장 단계와 관계없이 제공하는 기본 방.
- `pets/rest-{종}.webp`: 열 종의96×96 휴식 전용 도트 그림. 펫은 이 방에서 움직이지 않습니다. 알은 기존 공통 알을 씁니다.
- `background.webp`: 1536×1024 아지트 배경.
- `manifest.json`: 각 파일의 크기·SHA-256과 원화 구성 수.

승인된 책상·의자 폭288, 러그432, 캐릭터 프레임252, 펫 프레임 최대120을 유지합니다. 보물함은 왼쪽 아래의 `(145,970)`, 폭135입니다. 트로피는 폭72로 오른쪽 전시 선반에 올립니다. 작은 소품은 그림 속 픽셀만 누르게 하지 않고 큰 목록·상세에서 고릅니다.

소품의 책·배지·달력은 장식입니다. 학생이 읽은 실제 책이나 획득 배지를 그 안에 합성한 그림은 아닙니다. 문패의 이름은 앱에서 별도 글자로 그립니다. 방 안 좌표와 미리보기는 서버에 저장하지 않고 선택한 소품 ID만 저장합니다.

카탈로그·고정 배치는 `lib/readingHideoutCatalog.js`, 공통 검증은 `lib/readingHideout.js`에 있습니다. 원화 전달본이 있는 개발 환경에서는 `node scripts/import-hideout-art.mjs /path/to/hideout-refined-v2`로 다시 생성할 수 있습니다. 실행에 원화 전달본이나 이 스크립트는 필요하지 않습니다.
