# 책봄 독서 여정 뱃지 18종

새 동물 캐릭터와 어울리는 입체 금속·에나멜 훈장 컬렉션입니다. 6계열×3단계.

- shelf: 독자의 길(한때 '서재의 시작') — 세 권의 책
- completion: 완독의 성취 — 펼친 책과 완독 표식
- streak: 꾸준한 독서 — 독서의 불꽃
- review: 생각의 기록 — 깃펜과 기록
- pages: 페이지 탐험 — 나침반과 책장
- level: 독서 성장 — 상승하는 별

각 계열의 _1은 초급·브론즈, _2는 중급·실버, _3은 고급·골드입니다.
모든 PNG는 1254×1254 투명 배경입니다. 이미지에 글자를 새기지 않아 작은 UI에도 사용할 수 있습니다.
기존 뱃지 ID·획득 조건·경험치 보상은 변경하지 않았습니다.

실제 앱은 원본을 웹용으로 축소·인코딩한 512×512 WebP 18종을 사용합니다. 원본 픽셀을 별도로 편집하지 않았습니다. ReadingBadge가 모든 화면에 같은 이미지를 제공하며 미획득 상태는 CSS로 표시합니다.
